# 목책 배치

구현: 2026-09-06. `wooden_fence`는 중첩 가능한 가구 아이템이다. 100개 이상도 한 묶음으로 보관하며 개당 무게는 0.01, 기존 소지 무게 제한을 따른다.

알드윈(Aldwin)의 판매 목록에서 수량을 지정해 구매할 수 있다.

## 영지 꾸미기 통합 계획

설계 확정, 미구현 (2026-09-06). [영지 설계 §4](LAND_SYSTEM.md#4-영지-꾸미기-조경사의-도구함)의
**조경사의 도구함** 화면에 바닥·길·울타리 탭을 두고 목책 배치를 울타리 탭으로 옮긴다.
목책 더블클릭도 같은 화면의 울타리 탭으로 연결하며, 기존 설치된 목책을 통한
회수 진입을 유지한다. 목책 진입만으로 도구함의 바닥·길 편집 권한을 얻지는 않는다.

도구함은 반복 사용하며 사용료가 없다. 목책은 기존처럼 설치 시 한 개를 소모하고
회수 시 돌려받는다. 영지 외곽 변 설치·소유권·미납·회수 규칙은 그대로 따른다.
아래 조작·프로토콜 설명은 현재 구현 기준이다.

## 조작

- 인벤토리에서 목책 사용(더블클릭) → 배치 모드. 인벤토리가 닫히고 기존 이동 목표가 취소된다.
- 배치 모드 동안 소유 영지 전체에 지형 높이를 따르는 은은한 점선 1m 격자를 표시한다. 마우스 위치나 카메라 회전과 무관하게 유지하며 모드 종료 시 숨긴다.
- 지면 호버 → 1m 셀의 가장 가까운 변에 실제 모델 미리보기. 초록은 설치, 주황은 회수, 빨강은 배치 불가.
- 빈 변 클릭 → 목책 1개 소모·설치. 이미 놓인 목책 클릭 → 제거·가방에 1개 반환.
- 저장 응답을 기다리는 동안 다음 클릭은 무시한다. 수량은 서버 응답으로 갱신한다.
- 우클릭으로 이동하면서 배치 모드를 유지한다. 좌클릭은 설치·회수에 사용한다.
- Esc, Done으로 종료. 수량 0이어도 회수를 위해 모드는 유지된다.
- 모드 밖에서는 5m 이내에 놓인 목책을 우클릭해 다시 진입할 수 있다. 재접속 후 가방이 비어 있어도 회수 가능하다.

## 배치 규칙

살아 있는 캐릭터가 지상에서 배치 모드를 사용한다. 편집 대상은 캐릭터와의 거리·고도 차로 제한하지 않는다. 플레이어 간 거래 중에는 편집할 수 없다.
신규 설치는 해당 변의 양옆 셀 중 하나가 자기 영지이고 세금 미납이 없어야 한다. 영지 외곽 변도 허용한다.
물 깊이 0.1m 초과 또는 양끝·중간의 높이 차가 0.5m를 초과하면 설치할 수 없다.
회수는 소속 영지의 현재 소유 캐릭터만 가능하며 미납 상태에서도 허용된다. 가방이 무거우면 목책을 그대로 남긴다.

## 저장과 충돌

`FenceEdge { x, z, axis }`는 정수 격자 꼭짓점에서 +X 또는 +Z 방향으로 뻗는 1m 변이다.
인접한 셀에서 선택한 동일 변은 같은 키를 사용한다. X는 월드 랩 범위로 정규화된다.
SQLite `land_fences`는 `(x,z,axis,estate_id)`만 저장하며 기본 키는 `(x,z,axis)`이다.
소유자는 `estate_id`로 연결된 `land_estates.owner_id`에서 조회한다. 실행 중 캐시와 전송 데이터의 `owner_id`는 이 조회 결과다.
배치 모드 진입 시 소유권 캐시를 갱신하고, 회수 트랜잭션은 항상 영지의 현재 소유자를 검증한다.
기존 DB의 `y`, `owner_id` 열은 초기화 시 제거하며 목책 위치·소속 영지는 보존한다.
서버는 불러올 때 양끝·중간의 현재 지형 높이 중 최솟값을 계산하고 실행 중 캐시에 보관한다.
지형 저장 API는 서버 높이 캐시와 해당 타일에 걸친 목책 충돌을 갱신하고 변경 높이를 클라이언트에 전송한다.
브라우저의 지형 편집·로딩도 목책 표시와 로컬 충돌 높이를 함께 갱신한다.
목책 수정과 캐릭터·인벤토리 저장을 같은 트랜잭션으로 커밋한 뒤 메모리와 주변 클라이언트에 반영한다.
중복 설치·회수와 DB 실패 시 수량이 바뀌지 않는다.

`shared/src/fence.rs`가 변 양쪽의 N/S 또는 E/W 플래그만 만드는 공통 충돌 구현이다.
셀 전체를 막는 일반 가구 풋프린트는 플레이어 목책에 적용하지 않는다. 별도 캐시 항목을 사용하므로
회수해도 겹친 집 벽·다른 목책의 충돌은 유지된다. 높이는 모델과 같은 약 0.914m, 통행 층은 지상 0층이다.
서버는 32m 구획으로 목책을 인덱싱하고, 접속·이동·설치·회수 시 주변 플레이어에게 변경분을 보낸다.
브라우저는 인스턴스 렌더링을 사용하며, 브라우저 WASM과 NPC 클라이언트도 동일한 충돌을 적용한다.

프로토콜 v57: `StartFenceMode`, `EditFence`, `FenceMode`, `FenceVisibility`, `FenceEditResult`.
일반 가구 설치·회수와 영지 강제 해제 시 회수함 처리는 별도이며 [영지 설계](LAND_SYSTEM.md)를 따른다.
